# Resume and Portfolio Notes

## Short project description

NBA Player Impact Analyzer is an interactive Streamlit app that lets users create custom NBA rotations, compare lineup strengths, and generate projected final scores and box scores using player-level impact metrics.

## Resume bullet options

- Built an interactive NBA lineup comparison app in Python and Streamlit, using player-level impact metrics to project matchup results, generate box scores, and visualize lineup strengths across offense, defense, spacing, playmaking, and rebounding.

- Engineered a weighted lineup scoring system from player profile metrics and deployed it through a Streamlit dashboard with custom team selection, projected scores, player cards, and Plotly matchup visualizations.

- Cleaned and structured NBA player data into a final profile dataset, combining scoring, efficiency, playmaking, rebounding, and defensive features to support interactive sports analytics analysis.

## LinkedIn/GitHub portfolio summary

I built this project to explore how NBA players fit together in custom lineups. Instead of only ranking players individually, the app lets users build two rotations and compare them by offensive creation, defense, spacing, playmaking, and rebounding. The app then projects a final score, creates team and player box scores, and visualizes the matchup breakdown in Streamlit.
